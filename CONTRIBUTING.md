# Guia de Contribuição

Obrigado por seu interesse em contribuir com o Se Liberta Brasil! Este documento fornece diretrizes para contribuições.

## 🎯 Como Contribuir

### 1. Reportar Bugs ou Sugerir Melhorias

Abra uma issue descrevendo:
- O problema encontrado ou a sugestão
- Passos para reproduzir (se for um bug)
- Comportamento esperado vs. atual
- Screenshots, se aplicável

### 2. Adicionar Dados de Políticos/Candidatos

Para adicionar ou atualizar informações:

1. **Fork o repositório**
2. **Crie uma branch** para sua contribuição
3. **Adicione os dados** seguindo o schema em `docs/data-schema.md`
4. **Verifique as fontes**: Todas as informações devem ter fontes confiáveis
5. **Submeta um Pull Request**

#### Requisitos para dados:

- ✅ Informações verificáveis
- ✅ Fontes oficiais citadas
- ✅ Formato JSON seguindo o schema
- ✅ Sem opiniões pessoais ou vieses
- ✅ Dados atualizados

### 3. Contribuir com Código

1. **Fork e clone** o repositório
2. **Crie uma branch**: `git checkout -b feature/minha-feature`
3. **Faça suas alterações**
4. **Teste** suas mudanças
5. **Commit**: Use mensagens descritivas
6. **Push**: `git push origin feature/minha-feature`
7. **Pull Request**: Descreva suas mudanças

#### Padrões de código:

- Use nomes descritivos para variáveis e funções
- Comente código complexo
- Mantenha consistência com o estilo existente
- Adicione testes quando aplicável

### 4. Melhorar Documentação

Documentação clara é essencial! Contribuições para:
- README e guias
- Comentários no código
- Documentação de API
- Tutoriais e exemplos

São muito bem-vindas!

## 🔍 Processo de Review

Todos os Pull Requests passam por review:

1. **Verificação automática**: Testes e linting
2. **Review manual**: Código e dados são revisados
3. **Feedback**: Sugestões de melhorias, se necessário
4. **Merge**: Após aprovação

## ⚖️ Código de Conduta

### Nossos Valores:

- **Respeito**: Trate todos com respeito
- **Imparcialidade**: Dados factuais, sem vieses
- **Transparência**: Processos abertos e claros
- **Colaboração**: Trabalhe em conjunto

### Não aceitamos:

- Informações falsas ou não verificadas
- Conteúdo ofensivo ou discriminatório
- Spam ou autopromoção
- Ataques pessoais

## 📋 Checklist antes de Submeter PR

- [ ] Código/dados testados
- [ ] Documentação atualizada
- [ ] Fontes verificadas (para dados)
- [ ] Mensagens de commit descritivas
- [ ] Branch atualizada com main/master
- [ ] Sem conflitos

## 🙋 Dúvidas?

Se tiver dúvidas sobre como contribuir:
- Abra uma issue com a tag `question`
- Verifique issues existentes
- Revise a documentação
