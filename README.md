# Se Liberta Brasil

**Missão:**  
O Se Liberta Brasil é uma plataforma aberta e transparente que reúne informações sobre políticos e candidatos brasileiros. Nosso objetivo é facilitar o acesso da população a dados confiáveis sobre quem ocupa cargos públicos ou pretende concorrer em eleições futuras, ajudando cada cidadão a tomar decisões conscientes na hora do voto.

---

## 📋 Sobre o Projeto

Esta plataforma foi criada para promover a transparência política no Brasil, permitindo que cidadãos tenham acesso fácil e organizado a informações sobre:

- **Políticos atuais**: Informações sobre quem ocupa cargos públicos
- **Candidatos**: Dados sobre pessoas que pretendem concorrer em eleições futuras
- **Histórico**: Trajetória política e administrativa
- **Propostas**: Planos de governo e promessas de campanha

## 🚀 Como Usar

### Pré-requisitos

- Node.js 14+ (para a versão web)
- Git para clonar o repositório

### Instalação

```bash
# Clone o repositório
git clone https://github.com/lucasitdias/SE-LIBERTA-BRASIL.git

# Entre no diretório
cd SE-LIBERTA-BRASIL

# Instale as dependências (se houver)
npm install

# Inicie a aplicação
npm start
```
