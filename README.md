# SE-LIBERTA-BRASIL
**Missão:** O Se Liberta Brasil é uma plataforma aberta e transparente que reúne informações sobre políticos e candidatos brasileiros. Nosso objetivo é facilitar o acesso da população a dados confiáveis sobre quem ocupa cargos públicos ou pretende concorrer em eleições futuras, ajudando cada cidadão a tomar decisões conscientes na hora do voto.
